# FieldPilot Roadmap

Roadmap описывает направление разработки FieldPilot, а не фиксированные сроки релизов.

Главная цель MVP:

> Открыть веб-форму → загрузить документ → получить проверяемые соответствия → заполнить выбранные поля.

## v0.2 — Local Extraction

Превратить текст документа в структурированные характеристики.

- [ ] поиск пар `характеристика → значение`
- [ ] извлечение единиц измерения
- [ ] обработка таблиц
- [ ] нормализация регистра
- [ ] нормализация пробелов
- [ ] нормализация разделителей
- [ ] десятичная запятая / точка
- [ ] нормализация единиц
- [ ] русский язык
- [ ] английский язык
- [ ] сохранение исходной подписи характеристики
- [ ] сохранение источника найденного значения
- [ ] защита от очевидно ошибочного парсинга

Пример внутреннего объекта:

```text
sourceLabel: "Motor Power"
value: "61"
unit: "kW"
source: "Motor Power kw 61"
```

**Результат:** FieldPilot понимает, какие характеристики и значения присутствуют в документе, но пока не решает окончательно, куда их записывать.

## v0.3 — Matching Engine

Сопоставление документа с текущей формой.

- [ ] нормализация названий полей
- [ ] словарь синонимов
- [ ] русско-английские соответствия
- [ ] fuzzy matching
- [ ] token matching
- [ ] учёт единиц измерения
- [ ] отрицательные признаки несовместимости
- [ ] защита от совпадений только по единице измерения
- [ ] confidence score
- [ ] объяснение причины совпадения

Уровни:

- [ ] 🟢 высокая уверенность
- [ ] 🟡 требует проверки
- [ ] 🔴 низкая уверенность / не использовать

Принцип:

> Лучше пропустить характеристику, чем заполнить неправильное поле.

**Результат:** пользователь получает список предполагаемых соответствий документа и формы.

## v0.5 — Learning

FieldPilot начинает запоминать исправления пользователя.

- [ ] команда «Запомнить соответствие»
- [ ] `chrome.storage.local`
- [ ] локальный mapping
- [ ] использование сохранённого mapping в следующих документах
- [ ] приоритет пользовательского mapping
- [ ] управление сохранёнными соответствиями
- [ ] удаление неправильного mapping
- [ ] экспорт mappings
- [ ] импорт mappings

Пример:

```text
Max. Bending Length
→
Максимальная длина заготовки
```

**Результат:** при постоянной работе с похожими документами ручных проверок становится меньше.

## v0.6 — ChatGPT Bridge

Дополнительный режим для сложных случаев без собственного AI API.

- [ ] режим «Разобрать через ChatGPT»

- [ ] генерация строгого prompt
- [ ] JSON schema ответа
- [ ] копирование prompt в clipboard
- [ ] импорт ответа ChatGPT из clipboard
- [ ] валидация JSON
- [ ] проверка неизвестных полей
- [ ] confidence из AI-ответа
- [ ] `requires_review`
- [ ] показ источника

FieldPilot не должен:

- [ ] хранить OpenAI API key
- [ ] использовать собственный платный API
- [ ] автоматически управлять интерфейсом chatgpt.com
- [ ] автоматически отправлять сообщения от имени пользователя

**Результат:** сложные документы можно разбирать через уже доступный пользователю ChatGPT.

# После v1.0

Идеи, которые не должны мешать созданию MVP:

- другие Chromium-браузеры
- несколько документов для одного товара
- сравнение данных из нескольких источников
- шаблоны для разных классов документов
- shared mapping-файлы между пользователями
- дополнительные форматы документов
- пакетная обработка
- интеллектуальное определение нужных страниц PDF

Все эти функции рассматриваются только после того, как основной сценарий станет надёжным:

**документ → анализ → сопоставление → проверка → заполнение.**
